# Island Homes SVG assets

The application expects the supplied media under:
- public/video/hero.mp4
- public/video/hero-poster.jpg
- public/images/catalog-01.webp through catalog-14.webp

The source catalog PDF and original asset package were supplied during implementation and used to build the real-content copy, model pricing, feature list, contact information and visual direction.

The GitHub connector used for this update can write UTF-8 source files directly; binary attachments supplied in chat are not directly mountable into the GitHub write action. Keep the original media package as the source of truth and copy the optimized media into public/ before deployment.
